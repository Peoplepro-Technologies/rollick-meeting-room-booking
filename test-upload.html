Test User Upload Feature

Click to select a CSV or Excel file for user upload

Sample CSV Format:

username,email,password,role,active
john.doe,john@example.com,password123,admin,true
jane.smith,jane.smith@example.com,,user,true
mike.wilson,mike.wilson@example.com,,user,false

Expected Columns:

  • username (required): User's username
  • email (required): User's email address
  • password (optional): Password for admin users
  • role (optional): 'user' or 'admin' (default: 'user')
  • active (optional): true/false (default: true)
